\section*{Artifact Appendix}

\subsection*{Abstract}
This artifact provides the complete implementation of the Universal Lossless Tokenizer,
including training, evaluation, and reproduction scripts. The tokenizer implements
equilibrium projection principles from RIFT~\cite{rift2025}, with optional integration
of Harmonized Hyper-Connections (HHC)~\cite{miller2024hhc} for enhanced stability.
The approach draws on insights from modular harmonized connections~\cite{deepseek2024mhc}
and the Platonic Representation Hypothesis~\cite{miller2024prh}.

\subsection*{Reproduction}

\subsubsection*{Quick Start}
\begin{verbatim}
git clone https://github.com/curv-institute/universal_tokenizer
cd universal_tokenizer
git checkout PLACEHOLDER_COMMIT_HASH
uv venv .venv && source .venv/bin/activate
\end{verbatim}

\subsubsection*{Run Experiments}
\begin{verbatim}
# Run full experiment pipeline
uv run scripts/run_experiment.py --config configs/default.toml

# Evaluate tokenizer performance
uv run scripts/eval.py

# Encode sample data
uv run scripts/encode.py --input data/sample.txt
\end{verbatim}

\subsubsection*{Run Tests}
\begin{verbatim}
uv run pytest tests/
\end{verbatim}

\subsection*{Theoretical Background}
The Universal Lossless Tokenizer is grounded in several key theoretical contributions:
\begin{itemize}
  \item \textbf{HHC}~\cite{miller2024hhc}: Provides the relational coupling framework
        for maintaining stable representations across segmentation boundaries.
  \item \textbf{mHC}~\cite{deepseek2024mhc}: Informs the multi-scale representation
        strategy for handling variable-length token sequences.
  \item \textbf{PRH}~\cite{miller2024prh}: Establishes the ontological foundations
        for why lossless reconstruction is achievable through equilibrium projection.
\end{itemize}
